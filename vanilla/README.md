# go!go!vanillas APP 内チケプラ HTML

`index.html` をブラウザで開いてください。ローカルで動作します。

## 券面

添付画像に合わせ、公演情報は以下に固定しています。

- go!go!vanillas presents 「ぼくらのタイマン上等ツアー」
- 2026年11月29日（日）、17:00 / 18:00
- 広島県・BLUE LIVE 広島
- スタンディング・go!go!CLUB 最速先行

一覧の「チケットを見る」を押すと、動画のSmartTicket券面を表示します。ピンクの名義・公演欄、日時・会場、整理番号・料金、チケット番号・裏面情報の順に配置し、背景アニメーション・透かし・入場ボタン・PASSはAPKの素材を使用します。添付画像は公演データに反映しています。

一覧は動画の「本日のチケット」と同じ、公演画像・公演名・日付・Start・会場・席種・枚数・「チケットを見る」の構成です。更新・受取・チケット種別・矢印はAPK内の画像を使用しています。公演画像はAPKに含まれないため、提供動画から切り出しています。上部のiPhone風ステータスバーは描画しません。

## 設定

**home → 左上の☰** で「チケット設定」を開きます。

変更できる項目は、お名前、整理番号、料金、チケット番号、未使用／使用済み、使用日時です。公演情報は変更できません。設定と入場状態はブラウザに保存します。

旧新潟公演の保存データがある場合、名義などを引き継ぎ、公演と入場状態は広島公演の未使用に切り替えます。

## 入場の動作

1. ticket → カード → 入場画面に進む。
2. 名前・日付のある上部に2本指で触れ、GATEが出たら横へ半分以上スワイプ。
3. 使用メッセージを約1秒表示し、約0.5秒でフェードアウト。PASSを表示。
4. ×で券面に戻るとPASSと使用日時を反映。

PCでは上部をマウスで横ドラッグできます。キーボードはEnter → 左右キー2回 → Enter。チケットリスト左上の再読み込みボタンを押すと、使用日時とPASSを消して未入場に戻ります。home左上の設定やmy pageの「入場前に戻す」からも変更できます。

画面内のDEMO表記は削除しています。公式API・実際のチケットへの接続、実際の入場処理は行いません。APK・提供動画に基づく解析記録は `RESEARCH.md` に記載しています。

## フォント・アニメーション・ホーム

iPhoneでは端末標準の欧文・日本語フォントを優先します。Windows等ではAPKのRoboto・YuGothicを使い、ホーム見出しと下部ナビゲーションにはAPKのRobotoSlabを使用します。券面の公演名は動画と同じ位置で2行に分け、画面幅に合わせて縮小します。

券面背景はAPKのGIF全20フレームを欠落なく展開し、動画の16秒時点に近い13番目のフレームから100ms間隔で再生します。点線円は10秒周期の共通時計で回転し、選択変更による再描画で回転位置が戻りません。

HOMEは提供された実機画像に合わせ、メイン写真、moment、next live、大小のバナーを配置しています。APKの公開HOME取得処理を参照して取得した実際の画像を同梱し、表示時の通信を不要にしています。HOMEのnext liveは実機画像と同じ高松公演の公開配信データで、所有チケットの広島公演とは別の情報です。左上の「go!go!C...」ボタンからチケット設定を開けます。
